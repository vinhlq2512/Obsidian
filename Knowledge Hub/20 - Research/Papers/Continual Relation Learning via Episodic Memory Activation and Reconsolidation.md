# Continual Relation Learning via Episodic Memory Activation and Reconsolidation

## Tóm tắt một câu

EMAR dùng episodic memory activation và reconsolidation để giảm overfitting vào vài memory examples cũ trong continual relation learning.

## Vì sao cần cho kế hoạch

Đây là nền memory-based CRE trước ConPL. Đọc để biết replay/prototype/consolidation đã được xử lý thế nào trước khi đề tài chuyển trọng tâm sang prompt routing.

- Episodic memory activation.
- Reconsolidation objective.
