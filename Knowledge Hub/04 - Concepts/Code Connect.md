# Code Connect

## Định nghĩa

[[Code Connect]] là mapping giữa component trong Figma và component trong codebase để coding agent biết nên tái dùng component nào thay vì tự dựng lại từ đầu.

## Cách hiểu bằng lời của tôi

Design system chỉ hữu ích cho AI coding khi agent biết node design nào tương ứng file/component nào. Nếu thiếu mapping, agent phải đoán hoặc search, và code sinh ra dễ drift khỏi component chuẩn.
