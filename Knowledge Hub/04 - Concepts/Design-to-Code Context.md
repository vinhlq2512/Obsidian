# Design-to-Code Context

## Định nghĩa

[[Design-to-Code Context]] là representation có cấu trúc của design dành cho coding agent, giữ lại layout, style, token và component mapping cần thiết nhưng loại bỏ metadata nhiễu.

## Cách hiểu bằng lời của tôi

Screenshot cho agent nhìn được hình nhưng thiếu số đo chính xác. Raw JSON có số đo nhưng quá nhiều nhiễu. Context tốt nằm giữa hai cực: đủ chính xác để code đúng design system, đủ gọn để model reasoning được.
