# Prompt Engineering

## Định nghĩa

Prompt engineering là thực hành thiết kế input cho generative model để hướng model thực hiện đúng nhiệm vụ, đúng format và đúng mức ràng buộc.

## Cách hiểu bằng lời của tôi

Prompt là specification mềm. Nó mô tả vai trò, nhiệm vụ, context, ví dụ, constraints và output format cho model.

## Cần biết

- Prompt tốt nói rõ mục tiêu, dữ liệu đầu vào, tiêu chí và format đầu ra.
- Few-shot examples giúp model bắt chước pattern.
- Chain prompting chia task phức tạp thành nhiều bước.
- Constrained output giúp pipeline dễ parse và giảm lỗi format.
